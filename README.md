# Компаньон для SillyTavern (вариант A, v0.4)

Компаньон открывается панелью справа прямо в окне ST и сам добавляет состояние игрового дня в промпт.

## Установка
1. В ST: «Расширения» (значок кубиков) → **Install extension** → вставить ссылку на репозиторий (для приватного репозитория ссылка с токеном, см. ниже) → Install just for me.
2. Перезагрузить страницу ST. В верхней панели появится значок книги 📖: он открывает компаньон. Ширину панели можно менять, потянув за левый край.
3. Перенос данных: «Расширения → Компаньон → Загрузить файл переноса», файл `companion-migration.json` с данными и картинками готовит Claude. Без картинок можно и так: на claude.ai «Мастерская → Экспорт → Скачать JSON», затем в ST «Мастерская → Экспорт → Восстановить из JSON».
4. Обновления: «Расширения → Manage extensions» → у Companion кнопка обновления.

### Ссылка для приватного репозитория
GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token: доступ только к `silly_companion`, Repository permissions → Contents: Read-only. Ссылка для ST:
`https://<токен>@github.com/l3525999/silly_companion`
Токен никому не показывать и не присылать в чат.

## Что работает
- Весь компаньон (Игра и Мастерская) внутри ST. Данные хранятся у вас: `data/default-user/user/files/companion-db.json` и копия за каждый день `companion-db-ГГГГ-ММ-ДД.json`. Новые картинки: `data/default-user/user/images/companion/`.
- Состояние дня в промпте: дата, тип дня и правило, дежурная и её фаза, сколько дежурств, счётчики, кто ещё в овуляции, кто беременна. Вставляется системным сообщением на заданной глубине перед каждой генерацией. Настройки и предпросмотр текста: «Расширения → Компаньон».
- Лотерея и «Записать в журнал» сразу меняют то, что получит модель в следующем ответе.
- Полоса над компаньоном читает шапку последнего ответа (дата, время, тип дня, SUBJECT, фаза, AROUSAL, COMPOSURE, CREAMPIES, CONCEPTION, PANTIES в подсказке). Блоки между `<!-- GFX_START -->` и `<!-- GFX_END -->` не читаются.
- Если дата в шапке позже «сегодня» в журнале, «сегодня» сдвигается само (выключается в настройках). Если раньше, появляется кнопка «Сделать … сегодня». Если у дня нет дежурных, кнопка «Записать дежурными» берёт девушек из шапки (по имени из анкеты).

- Перенос с claude.ai вместе с картинками: «Расширения → Компаньон → Загрузить файл переноса» (`companion-migration.json`, его готовит Claude). Если в ST уже были данные, они сохраняются в `companion-db-before-import.json`.

- «Журнал сам»: из последнего ответа берутся пост Slutify (заголовок, описание кадра, подпись, комментарии, лайки) и GM's Notebook и записываются в день из шапки (коллекция `stories`). Подпись видна на листке дня, если своя заметка пуста; всё целиком в окне дня, блок «Из истории». Свайп или правка ответа заменяют запись.
